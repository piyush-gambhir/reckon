---
title: Tool belt
description: The CLIs Reckon runs for development, operations, product and growth work, and the evidence each one covers.
---

Reckon runs existing CLIs, one connection at a time, through
`reckon run <connection-or-tool> -- <arguments>`. It does not wrap them in a new
binary. Setup installs them (see [Setup](/docs/installation)).

## Development

| CLI | Provider | Evidence it covers |
| --- | --- | --- |
| `jenkins` | `jenkins` | Jobs, builds, pipeline stages, test reports, console logs |
| `gh` | `github` | Pull requests, Actions runs, releases, issues |
| `kubectl` | `kubernetes` | Pod and deployment state, events, rollout history |
| `aws` | `aws` | CloudWatch metrics and logs, load balancers, ECS, SQS |

## Operations

| CLI | Provider | Evidence it covers |
| --- | --- | --- |
| `cubeapm` | `cubeapm` | Distributed traces, PromQL metrics, LogsQL logs, dependencies |
| `grafana` | `grafana` | Alerts, silences, annotations, dashboards, datasources |
| `es` | `elasticsearch` | Elasticsearch cluster health, indices, Query DSL and SQL search |
| `nginxpm` | `nginxpm` | Proxy hosts, redirections, streams, certificates, audit log |
| `psql` | `postgres` | PostgreSQL activity, locks, plans, replication |
| `mysql` | `mysql` | MySQL sessions, plans, InnoDB state, replication |
| `mongosh` | `mongodb` | MongoDB running operations, replica set state, bounded samples |
| `clickhouse client` | `clickhouse` | ClickHouse tables, query log, metrics, events |
| `redis-cli` | `redis` | `INFO`, `SLOWLOG`, `LATENCY`, `DBSIZE` and `SCAN` diagnostics |
| `kcat` | `kafka` | Kafka metadata and group-less topic reads |
| `rpk` | `kafka-rpk` | Kafka consumer-group lag, cluster and topic state |

## Product

| CLI | Provider | Evidence it covers |
| --- | --- | --- |
| `jira` | `jira` | Issues and their history, boards, sprints |
| `clarity` | `clarity` | Dashboard exports, session recording samples, analytics questions |

## Growth

| CLI | Provider | Evidence it covers |
| --- | --- | --- |
| `gsc` | `gsc` | Google Search performance, trends, opportunities, URL inspection, sitemaps |
| `bwt` | `bing` | Bing traffic, top queries and pages, crawl health |

`jq` helps with structured output. Investigations can also read a local Git
repository (`git show`) as typed evidence.
